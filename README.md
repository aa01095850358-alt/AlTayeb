# تطبيق الطيب — نسخة أولية

هذه نسخة Android Studio أولية لواجهة تطبيق "الطيب" للغرف الصوتية.

تحتوي حالياً على:
- شاشة الغرف الصوتية
- أمثلة لغرف
- دخول وخروج من الغرفة
- زر كتم/تشغيل الميكروفون
- تصميم RTL عربي

مهم: الصوت الحقيقي بين المستخدمين يحتاج خادم/خدمة Real-Time مثل WebRTC أو LiveKit، وهذه النسخة هي واجهة أولية وليست خدمة غرف صوتية حقيقية بعد.

لفتح المشروع: Android Studio > Open > اختر مجلد AlTayeb.
